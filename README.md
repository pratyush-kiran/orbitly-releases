## First release

Orbitly 0.6.0 is an **unsigned** Windows x64 installer. Windows may show an unknown
publisher. Check the SHA-256 supplied with each release before installation.
Windows 10 22H2 (build 19045) or Windows 11 is required.

Source code for the application is maintained in a private repository. This
repository contains public release metadata and binaries, not private application
source. Original software copyright 2026 Atharv Gogia, MIT licensed. Third-party
licences and FFmpeg build/source provenance are bundled with the installer.

See each release's notes for tested behavior and known limitations.
